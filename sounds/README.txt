Place standard .wav files in this folder, then open:

  /burst -> Options -> Sound -> Refresh Sounds

Burst discovers files without executing them. The selected exact filename is
saved. Burst-window and confirmation selections safely fall back to None when
missing.

Record Breaker's default sound is:

  celebrate.wav

The Record Breaker selection is preserved even when its file has not been
copied here yet, so adding celebrate.wav later activates it without resetting
the UI choice. Any discovered WAV can be selected and tested instead.
